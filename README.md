Production build of the MyBank register and login app, published for use as an Akamai origin.

Site: https://satyamangipudi888.github.io/

Akamai property origin:

- Origin hostname: `satyamangipudi888.github.io`
- Origin type: your origin
- Ports: 443 HTTPS only
- Forward host header: origin hostname
- Origin path: empty
